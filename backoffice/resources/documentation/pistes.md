Les **suggestions envoyées par les utilisateurs de l'app** : une salle, un spectacle ou une billetterie qui manque à Spettacoli.

Les pistes qui parlent de la même chose sont **regroupées sur une ligne** ; les plus demandées et celles des villes pilotes passent d'abord.

### Ce que vous voyez

- **Proposé par** : le nombre de personnes ; **Commentaires** : ce qu'elles ont écrit.
- **Déjà couvert** : le lieu existe déjà dans le catalogue ; il manque peut-être seulement certains spectacles.
- **Du lieu** : une personne qui travaille pour ce lieu a fait la proposition (candidat à un espace salle).
- **Statut** : Nouvelle → Étudiée → Intégrée ou Écartée.

### Les actions

- **Ouvrir le lien** : le site donné par l'utilisateur.
- **Créer le lieu** : ouvre la création d'un lieu dans un nouvel onglet (pistes de type salle).
- **Étudiée** : indique que vous regardez la piste. Rien n'est envoyé.
- **Intégrée** : la piste est maintenant dans Spettacoli. **Un e-mail est envoyé à chaque personne du groupe**, avec une phrase personnelle facultative. Vous pouvez relier le lieu du catalogue.
- **Écarter** : choisissez un motif (voir **Motifs de refus**). **Un e-mail est envoyé à chaque personne du groupe.**
