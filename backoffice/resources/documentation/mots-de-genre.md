Les mots qui **donnent un genre** à un spectacle quand la source n'en donne pas (ou le marqueur « Jeune public »). Exemple : « stand-up » → Humour.

Le mot est cherché dans le titre, puis dans la description, sans tenir compte des accents ni des majuscules, au singulier comme au pluriel. **Le mot le plus long l'emporte** (« comédie musicale » avant « comédie »).

### Les actions

- **Ajouter un mot** : le mot ou l'expression, le genre donné, et/ou « Marque aussi le spectacle Jeune public ». Sans genre, le mot ne sert qu'au marqueur Jeune public.
- **Actif** : désactive un mot sans le supprimer.
- **Modifier / Supprimer**.

Pris en compte dès la collecte suivante.
