Les listes de mots qui décident **si une annonce est du spectacle vivant**. Ce sont elles qui calculent le score expliqué dans **À trier**.

- **Inclure** : le mot ajoute des points (ex. « théâtre », « concert »).
- **Exclure** : le mot en retire davantage (ex. « exposition », « visite guidée »).

Le poids dépend de l'endroit où le mot est trouvé : catégorie de la source (fort), titre (moyen), description (faible). Comparaison sans accents ni majuscules, au singulier comme au pluriel.

### Les actions

- **Ajouter un mot** : choisissez l'effet (Inclure / Exclure) et le mot. Aussi possible depuis **À trier** (« Ajouter un mot »).
- **Actif** : désactive un mot sans le supprimer.
- **Modifier / Supprimer**.

Pris en compte dès la collecte suivante. Un mot mal choisi peut exclure de vrais spectacles : en cas de doute, préférez traiter quelques annonces dans **À trier**.
