Les **comptes du back-office**. Réservé aux super admins.

### Les actions

- **Créer** : nom, e-mail, mot de passe (12 caractères minimum) et **modèle de profil** :
  - un modèle (ex. « Trieur ») : le compte ouvre les menus du modèle, et **modifier le modèle change aussitôt ses menus** ;
  - **Libre** : cochez les menus de ce compte seulement.
- **Modifier** : laisser le mot de passe vide pour ne pas le changer. **Actif** décoché : le compte ne peut plus se connecter.
- **Supprimer** : depuis la fiche, sauf pour votre propre compte.

Vous ne pouvez pas changer le modèle ni désactiver votre propre compte. La double authentification est obligatoire pour tous : chacun la configure à sa première connexion.
