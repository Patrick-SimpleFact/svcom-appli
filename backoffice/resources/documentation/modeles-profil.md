Les **modèles de profil** : quels menus ouvre chaque type de compte du back-office. Réservé aux super admins.

### Les actions

- **Créer** : un nom (ex. « Trieur ») et les menus cochés, groupe par groupe. Le compte ouvre aussi toujours la **Boîte de travail** (avec seulement ses files) et la **Documentation** (avec seulement ses menus).
- **Modifier** : les comptes qui suivent le modèle reçoivent les nouveaux menus aussitôt.
- **Supprimer** : seulement un modèle qui n'a plus de compte.

Le modèle **Super Admin** ouvre tout, y compris les comptes et les modèles ; il ne se modifie pas et ne se supprime pas. Pour un compte à part, choisissez **Libre** dans **Administrateurs**.
