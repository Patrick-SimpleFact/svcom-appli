Les **bandeaux affichés dans l'app** (maintenance, incident, salle fermée…), sans publier de nouvelle version.

### Les actions

- **Nouveau message** : le texte (court, 200 caractères au plus), le type (**Information** ou **Alerte**, en rouge), la période d'affichage (sans fin : jusqu'à ce qu'on le désactive) et la ville (vide : toutes les villes ; sinon seulement les utilisateurs de cette ville).
- **Actif** (interrupteur) : retire le bandeau tout de suite, sans le supprimer.
- **Modifier / Supprimer**.

La colonne **État** indique si le message est programmé, en cours, terminé ou désactivé.
